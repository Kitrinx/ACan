# African Expedition - The Board Game

African Expedition. A board game with saves, a pause, and no
secrets at all.

## Cheat codes and hidden input

There are none.

## What there is

**Select then Start returns to the title** from anywhere in a game.

**The dice are the frame counter.** Every random choice in the game samples
the frame counter at the moment of the press. There is no other source of
randomness, so outcomes depend on exactly when you press the button.

**Multitap support.** The game asks the sound driver how many pads are on each
port and reads up to seven pad slots: four or more on the first port gives four
human players, more than one on the second port raises it to five.
