# English translations

These expect little-endian ROMs. The source file names may vary. I use more faithful chinese translations
if the file names than the older awkward google translate ones (eg "Journey to the Laugh"). Journey to the Laugh
actually is a chinese pun where "West" and "Giggle" are close to one another, so it's supposed to be a punny
parody of Journey to the West, so I tried to find an english equivilent with "Jest" which sort of captures the joke.
"Monopoly" in Taiwanese chinese refers to any board game that uses dice, for example.

These games were translated using AI. I figured nobody had done it in the last 30 years, I'd rather be able to play them with potentially imperfect
translations than not play them at all. I did a reasonable amount of QA work to try to ensure they weren't terrible and awkward and broken, but there
may be some weirdness. If there is, please open an issue in the github and I will fix it.
