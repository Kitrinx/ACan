Text the developers left in the cartridges, read straight out of the ROMs.
Offsets are into the cartridge image in 68000 byte order.

== Magic Cue Pool (Taiwan)
  $00046E  'Nu1996 12 01 funthech all rights reserved gxl'
  $001818  'swtq.tsk ver105 95.12.26'
  $0208C4  'guo xiao lin 1996 12 01 copy right'
  'funthech' is the ROM's own misspelling. 'gxl' and 'guo xiao lin' are the same
  person. 'swtq.tsk ver105 95.12.26' is a module banner a year older than the
  main build, parked just after the reset entry where the CPU jumps over it.
  The 1 MiB program is stored twice to fill the 2 MiB part, and 23 KB of the
  developers' assembler source is in the image - see the .asm file beside this.

== Great Formosa Showdown, The (Taiwan)
  $000400  "Lancelot 002 95'"
  Project codename 'Lancelot', build 002, 1995. The only developer text in the
  ROM. The publisher's logo card reads 'AV artisan'.

== Rebel Planet (Taiwan)
  $005F86  'PROGRAMER JUH0WEN0HER'
  Not decoration: the game compares this string against the first 22 bytes of
  the cartridge save, and a mismatch starts a new game. The programmer's name is
  the save file's signature. The zeros stand in for spaces.
